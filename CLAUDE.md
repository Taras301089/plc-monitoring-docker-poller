## Автоматическое тестирование фронтенда после изменений

После любых изменений файлов в `fastapi-api/static/`:

### Процесс:
1. **Пересобрать контейнер** (без кэша):
   ```bash
   docker compose down fastapi-api && docker compose build --no-cache fastapi-api && docker compose up -d fastapi-api
   ```

2. **Открыть браузер и протестировать**:
   - Использовать встроенный браузер: `mcp__Claude_Browser__preview_start`
   - URL: `http://localhost:8000`
   - Ctrl+Shift+R для очистки кэша

3. **Проверить функциональность**:
   - ✅ Страница загружается без ошибок
   - ✅ Кнопки "Обновить с ПЛК" и "Загрузить из БД" работают
   - ✅ Кнопки "Развернуть все" / "Свернуть все" работают
   - ✅ Data Blocks развертываются/сворачиваются при клике
   - ✅ Переменные отображаются внутри Data Blocks
   - ✅ Чекбоксы (выбор, архив, Grafana, авария) работают
   - ✅ "Сохранить выбранные" работает

4. **Если тесты не пройдены**:
   - Добавить `console.log()` для отладки в браузере
   - Проверить `read_network_requests` чтобы увидеть что приходит с API
   - Исправить код и повторить с шага 1

## Веб-интерфейс PLC Variable Browser

**Путь**: `fastapi-api/static/index.html`  
**API сервер**: `fastapi-api/main.py`  
**Функции**:
- Иерархическое отображение переменных (древовидная структура как в WinCC)
- Развернуть/свернуть Data Blocks
- Поиск по Data Block и имени переменной
- Выбор переменных для сохранения
- Опции: архивирование, Grafana, авария

## Примечания

- Контейнер fastapi-api должен быть пересобран при любых изменениях HTML/CSS/JS
- Старый кэш может остаться в браузере - всегда использовать Ctrl+Shift+R
- При проблемах с группировкой переменных проверить функцию `groupByDb()` в HTML
