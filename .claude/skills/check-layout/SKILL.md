# Проверка вёрстки на разных экранах

Цель: найти наложения и обрезанный текст до того, как их увидят на ноутбуке или телевизоре.

## Порядок

1. Пересобрать контейнер, если менялись файлы в `fastapi-api/static`:
   `docker compose down fastapi-api && docker compose build --no-cache fastapi-api && docker compose up -d fastapi-api`
2. Открыть страницу во встроенном браузере (`mcp__Claude_Browser__preview_start` с `url` или `navigate`) на `http://localhost:8000/#andon` (для других экранов нужный хэш: `#charts`, `#reports`, `#downtimes`). Вкладка должна быть на переднем плане (`tabs_select`), иначе таймеры страницы замирают.
3. Выбрать ПЛК и линию, чтобы таблица загрузилась (на Andon это `#plc` → значение `7`, событие `change`; загрузка занимает до 20 секунд).
4. Для каждого размера из списка: `resize_window` (ширина × высота), подождать 2–3 секунды, выполнить скрипт `overlap-check.js` из этой папки через `javascript_tool` (вставить его текст целиком), затем сделать скриншот.
5. В конце вернуть окно в обычный размер: `resize_window` с `preset: "desktop"`.

## Размеры (ширина × высота, CSS-пиксели)

| Что имитирует | Размер |
|---|---|
| Монитор Full HD | 1920 × 1080 |
| Ноутбук 1920×1080 с масштабом 125% | 1536 × 864 |
| Ноутбук 1366×768 | 1366 × 768 |
| Ноутбук с масштабом 150% | 1280 × 720 |
| Окно на пол-экрана | 955 × 900 |
| Телевизор / табло (включить режим табло: `document.querySelector('#andon-tv').click()`) | 1920 × 1080 |
| Планшет | 768 × 1024 |

Минимум для небольшой правки: 1920, 1366, 955. Для правки шапки или таблицы Andon: все размеры.

## Что считать проблемой

- В отчёте скрипта `overlaps` не пустой: блоки пересекаются (кроме вложенных друг в друга). Исправлять вёрстку, а не прятать блок.
- `clipped` содержит элементы, чей текст не помещается без многоточия: заголовки колонок, числа, кнопки. Многоточие у «Причины» допустимо.
- `hscroll: true`: у страницы горизонтальная прокрутка. Известная причина: полоса вкладок шире окна на 955px (не новая проблема); новые причины исправлять.
- На скриншоте: нечитаемые цифры, обрезанные подписи, кнопки на тексте, пустое место на пол-экрана.

## Отчёт пользователю

Коротко: какие размеры проверены, что нашли и исправили, что осталось. Напомнить, что финальная проверка на ноутбуке и телевизоре за пользователем (обновить страницу Ctrl+Shift+R).
