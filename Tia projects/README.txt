Changan/UB+MB: копия содержимого VCI-экспорта из C:\TIA_Exports\Changan_UB_MB\UB+MB_PLC1.
Содержит 1119 XML: программные блоки, PLC tags и PLC data types.
Остальные семь разделов пока пустые: готовых полных XML-экспортов для них не обнаружено.

Это экспорты инженерной логики, а не текущие значения сигналов PLC и не полные проекты .ap17.
Исходные проекты и экспорт Changan оставлены на прежних местах.
Папка Tia projects хранится в Git и переносится на другой ПК при clone/pull.
Для чтения XML установка TIA Portal не требуется. Для новых экспортов через
TIA Connector требуется Windows, TIA Portal V17 и Openness.
PMM пока не загружает эти файлы автоматически: интеграция с сайтом ещё не реализована.
Для следующего VCI-экспорта выбирайте соответствующую папку бренда и раздела.
