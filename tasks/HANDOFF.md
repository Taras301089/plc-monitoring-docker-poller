## 4. Решения пользователя (не переспрашивать)

- Цифра «Простой, мин» = отставание от плана: (план − факт) / план × длительность интервала; формулу не менять. Колонку назвать «Отставание, мин», подсказка «Отставание от плана, мин: …» (делается в T-14 окне «Названия»). «Простой RB262/BDC» и «Простой весь день» не переименовывать (реальные остановки).
- Ответственный: ПР / ОТО / ИТО / ДР («Другое», внешние причины, описание обязательно). ОТО/ИТО → «ждёт подтверждения»; ответы отделов (согласен / частично / не согласен → «спорно») это шаг 2 T-15; спорное в отчётах отдельной строкой; срока нет, отвечать можно в любой следующий день.
- Подстановка отдела из справочника причин выключена (`OWNER_AUTOFILL = false` в `downtime.js`) до согласования соответствия «причина → отдел» с коллегами (T-18).
- Мастера на линии без ноутбуков: основной канал Telegram (T-16, после шага 2 T-15).
- **Любые вопросы с выбором только интерактивными кнопками (`AskUserQuestion`); пользователь напомнил об этом 20.10 с упрёком.** Ответ «Другое» своим текстом иногда теряется, тогда переспросить обычным текстом.
- Вопросы кнопками (`AskUserQuestion`), но **если пользователь отвечает своим текстом, ответ иногда теряется**: при вопросах со свободным ответом спрашивать обычным текстом.

## 8. Рабочие приёмы

- Воркеры: Agent с `isolation: worktree` (worktree от последнего коммита: незакоммиченные файлы передавать явно или работать в основной папке); два воркера не правят один файл.
- Git Bash: для `docker exec` с путями `MSYS_NO_PATHCONV=1`; Python в консоли печатать с `PYTHONIOENCODING=utf-8`.
- Окончания строк: многие файлы CRLF, сохранять как было; `.ps1` с BOM.
- `APP_ENV=dev` на этом ПК (запись в ПЛК и Telegram запрещены); `prod` только на сервере.

- **Docker Desktop на этом ПК** (Windows 11 сборка 26300) не стартует после закрытия: ошибка Windows, файлы-сокеты AF_UNIX нельзя удалить и переименовать (воспроизведено без Docker). Запускать только скриптом `C:\Users\t.ukrainets\bin\start-docker.ps1` (вне Git): он переименовывает `Docker\run` и `docker-secrets-engine`, делает `wsl --shutdown` и запускает Docker. Есть ярлык «Start Docker PMM» на рабочем столе и задача «Start Docker (PMM)» при входе в Windows; автозапуск Docker из реестра удалён. Не нажимать «Reset to factory defaults» (стирает базу). Старт занимает 1–6 минут. Подробности в памяти `reference_docker_stale_sockets.md`.
- `gh` на этом ПК не установлен: запросы на слияние делает пользователь на GitHub.
